# Caminho Druídico Pro Ultimate

Aplicação web progressiva (PWA) de ferramentas e sabedoria baseada na doutrina **OBOD** (*Order of Bards, Ovates and Druids*). Desenvolvida para apoiar práticas contemplativas, rituais, oráculos e estudos da natureza, com funcionamento 100% offline.

## 🌟 Funcionalidades
* **Oráculos**: Oráculo de Ogham (20 letras sagradas) e Runas Elder Futhark.
* **Ciclos Naturais**: Astronomia com cálculo dinâmico de fases lunares e horários solares.
* **Orientação**: Bússola interativa com geolocalização GPS e alinhamento elemental (Norte, Sul, Leste, Oeste).
* **Roda do Ano**: Diagrama SVG interativo dos 8 festivais sagrados célticos.
* **Prática & Comunidade**: Informações sobre os Graus OBOD, links de organizações internacionais e Tríades de Barddas.
* **Ferramentas Rituais**: Construtor de rituais com pré-visualização em pergaminho e diário integrado com suporte a backups JSON e exportação TXT.
* **Imersão**: Sintetizador de áudio ambiente (Chuva e Vento) e ciclo de respiração guiada Awen.

## 🛠️ Tecnologias
* HTML5, CSS3, Tailwind CSS (CDN) e JavaScript Vanilla.
* Service Worker & Web App Manifest para PWA.
* Armazenamento local (`localStorage`) para persistência de diários e temas.
